# 晶缘 · 今日水晶能量建议

这是一个纯前端单页水晶占卜/推荐网站，适合摆摊、私域活动或线下体验时通过二维码让顾客快速访问。

## 功能

- 年、月、日分开选择出生日期，默认 `1997-09-01`
- 今日祈愿支持多选，也可以不选
- 前端自动根据出生日期推算太阳星座与年份五行
- 根据星座、五行、祈愿方向和水晶属性匹配 Top 3 推荐
- 生成过程包含约 5 秒进度条与分阶段提示
- 结果使用左右箭头切换 Top 1 / Top 2 / Top 3
- 每款水晶展示实物手串图、适配度、能量评分、幸运色、命盘要点与详细能量解析

## 技术说明

- 纯 HTML / CSS / JavaScript
- 不依赖后端
- 不存储用户数据
- 可直接部署到 GitHub Pages
- 已包含 32 款常见水晶实物图资源
